mattpocock/skills:给 AI 程序员的「工作手册」

作者 Matt Pocock(TypeScript 名师),直接公开自己每天在用的 .agents 目录

🤖💥

AI 写代码,常踩四个坑:

👂❌没听懂你要什么
做出来不是那回事
🗣️💬废话太多
20 个词说 1 件事
🧨代码是坏的
没有测试兜底
🏚️越写越乱
架构加速腐烂
↓
🃏📖

解法:把工作习惯拆成一张张「技能卡」。每张卡 = 一小段纪律,小巧、可拼、换任何模型都能用。
不是抢你方向盘的框架,是随取随用的招式。

↓

招式分两种角色

🎖️你主动召唤的输入 /grill-me 这种,当「指挥官」,编排流程
🧰AI 自己会拿的干活时自动触发,是「基本功」:tdd、code-review…

规矩:指挥官可以叫基本功,指挥官之间不互相叫。

↓

一条标准流水线

🔥🍖/grill-me — 先「拷问」你AI 连环追问,把方案的每个分支问清楚才动手
↓
📝/to-spec → /to-tickets聊天变规格书,再切成一张张带依赖的小票
↓
⚒️/implement — 边测边写红-绿-重构循环,写完自动双轴 code-review
↓
🪞/retro — 干完复盘反过来改进你的环境和规范
↓

百宝箱里还有什么

🏃📄handoff对话压缩成交接文档,换个 AI 接着干
🩺diagnosing-bugs先造复现环,再假设、下探针、修复
📚research查一手资料,产出带引用的笔记
🧱prototype一个 HTML 快速验证设计问题,用完就扔
🗂️domain-modeling维护术语表 GLOSSARY.md,少说废话
🧙wizard生成交互脚本,带你做只有人能做的步骤
❓wait-whatAI 说人话听不懂时,用术语表重讲一遍
🧭ask-matt / wayfinder不知道用哪张卡?跨会话大计划?
↓
🧰⚡

装上就能用,每个仓库先跑一次配置:

claude plugin install mattpocock-skills@claude-plugins-official
Codex / Copilot / Gemini CLI 也支持;通用装法:npx skills@latest add mattpocock/skills,然后跑 /setup-matt-pocock-skills

一句话记忆:它把「老工程师的纪律」印成卡片,AI 照着出牌。

ui-ux-pro-max-skill 是什么？

一个开源（MIT）的 Agent Skill，GitHub 上 14 万+ Star ⭐ —— 专门教 AI 写出「设计师水平」的界面

先 看 一 个 痛 点

会写代码的宝宝，不等于会配色

让 AI 搭界面，功能都对，可出来的页面总像「程序员的审美」。

AI 缺的不是代码能力，是审美和设计经验：什么产品该配什么色、什么字体、什么版式。

ui-ux-pro-max = 给宝宝的一整套「设计学院教材」📚 一个 Agent Skill 小书包，里面装着一位资深设计师的全部套路：
说明书（SKILL.md）＋ 设计数据库（CSV 素材册）＋ 检索引擎（Python 脚本）
打 开 书 包 看 看

三个格子，对应三种宝物

素材册里全是真家伙：192 套配色、74 组字体搭配、79 种设计风格、119 条 UX 准则、192 条行业推理规则。

它 是 怎 么 干 活 的

四步流水线：从一句话到一套设计系统

你说「帮我做个 SaaS 落地页」，它在幕后跑完这条流水线。

最贴心的一格是 🚫 禁忌清单：金融 App 别用什么、医疗网站忌讳什么——先排雷，再设计。

怎 么 装 到 你 的 机 器 上

两种上货方式，24 个平台都能装

24 个 AI 助手：Claude Code · Cursor · Windsurf · Copilot · Codex · Kiro … 自动触发：直接说「给我的 SaaS 产品做个落地页」 手动触发：敲 /ui-ux-pro-max

装好后它就静静躺在技能列表里，聊到 UI 就自动上岗，不用天天念咒。

设 计 师 的 最 后 一 关

交货前还要过「质检流水线」

不光生成方案，还替你把好最后一道关。

对比度、键盘焦点、prefers-reduced-motion（尊重「减少动画」偏好）、窄屏适配——四关全过才算合格。

还有这些小心思 🎁 MASTER.md：把定稿的设计决策存成「大师笔记」，换页面不跑偏 · RTL 模式：阿拉伯语等从右到左的语言自动适配 · 旧主题迁移：给已有应用换肤，先审计再动手
